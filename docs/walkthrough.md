# 短时复核路径

环境准备和镜像构建在操作前完成。服务的健康入口是 `/health`；服务启动即继续，不固定等待。正常本地启动在数秒内完成。若90秒内没有就绪，应停止操作并保留错误，不把等待算作成功运行。

从首页选择课程类别、当地约束和质量门槛，查看中心投入产出原始比率的图表与明细，再阅读下方“相对效率与改进空间”专区：表格按中心原始顺序展示 CRS、VRS、规模效率与 Banker–Morey 调整 VRS，不提供排名。点击一条效率记录，在详情区核对参照组合权重、每项投入的当前值/目标值/差距比和原始单位，以及产出目标；使用“查看原始记录”回到源数据核对。

改变质量门槛后重新查看，稳定性区块会对照门槛 0 的基准说明得分与参照组合是否变化；把课程类别、当地约束和门槛收紧到没有合格参照对象时，页面明确显示“缺可比对象”及原因，而不是给出发散或默认得分。输入会议名称并保存，然后改变所选范围；点击左侧刚保存的记录核对先前材料（含效率结果）仍能打开，最后导出当前记录。整段交互通常需要45至90秒，不依赖远程请求。

`fixtures/data.json` 可用于重新导入核对。页面说明的是观测和适用范围；不要为了演示修改数据以制造某种优胜、显著性或异常结论。新增加的分析也应从真实可用证据解释结果，不要求出现某个指定方向。
