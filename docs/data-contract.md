# 数据口径

centers 包含所属课程 family、固定场地 constraint 和可调整投入。inputs 中 staff_hours、equipment_hours、funding 量纲不同，space 为不可控条件。outputs 中 completed、complex_modules 为教学量，quality 是已测质量比例而非额外产量。null 表示缺报；0 表示真实零。单位换算由 units 描述，不包含预定效率或排名。

## 相对效率与改进空间

相对效率使用投入导向的数据包络分析（DEA 包络形式），只在所选比较组内度量到前沿的相对距离，不产生绩效排名，也不认定任何中心管理存在问题。页面并列三类模型，避免单一比值包办判断：

- CRS（恒定规模报酬）得分包含规模因素；VRS（可变规模报酬）得分剔除规模差异；规模效率 = CRS / VRS，并给出规模报酬方向提示。
- Banker–Morey 调整 VRS 只允许缩减可调整投入；space 等不可控条件只要求参照对象处于相同或更紧的条件，不参与 θ 缩放。
- quality 不作为产出，而是参照对象的资格门槛。门槛为 0 表示不设门槛；提高门槛后，未达标或质量缺报的中心不能作为参照对象，但仍以自身数据接受评估。稳定性区块以门槛 0 的同组结果为基准，对比 VRS 得分与参照组合的变化。
- 参照组合（peers）是数学上的线性参照对象，权重之和在 VRS 下为 1；它用于解释每项投入的当前值、目标值、松弛与差距比，不代表现场可直接执行的缩编方案。

## 缺报、零产出与可比对象边界

- 可调整投入缺报（如 funding 的 null）在比较组内整列剔除，不做插补，并在处理边界中说明；原始记录仍保留 null。
- 产出缺报的中心不能进入参照前沿，自身也因产出约束不完整而标记为“缺可比对象”，不编造得分。
- 真实零产出保留在原始数据中；含零产出维度的中心不进入参照前沿（径向模型在零值上会退化），其自身只要产出约束完整仍可接受评估；全部产出为零时投入导向径向模型不适用，明确标记原因。
- 比较组过窄或门槛过高导致没有合格参照对象时，所有中心返回“缺可比对象”及原因，而不是空结果或默认值。参照对象少于 6 个时给出区分度有限提示。
- 求解前对每个指标列做常数缩放，更换计量单位（如经费由元改为万元、工时乘以常数）不会改变效率得分、参照组合与权重；目标值按原始单位呈现，可在页面与原始记录核对。

## 数据版本

`fixtures/data.json` 是可直接导入的一份完整材料，`product.json` 保存页面默认范围（课程类别、当地约束、质量门槛）。导入必须提交完整对象，不把省略字段解释为删除补丁；以规范化 JSON 的 SHA-256 标识内容，同内容多次导入复用版本。原始记录只追加版本，保存的分析材料始终指向原来版本，并冻结当时的选择条件与完整效率结果。

页面中的范围影响当前描述，不回写源数据。`null`、缺记录与实际零不能合并；数据格式问题应在导入时明确报错，而不是生成看似成功的空结果。涉及单位、时间或关系的解释以本文件为准，统计方法和业务决策没有预设结果。

## 目录

`teaching_frontier/domain.py` 提供现行领域校验和描述，`efficiency.py` 实现相对效率分析与边界处理，`lp.py` 是仅依赖标准库的两阶段单纯形求解器，`validation.py` 处理基础引用与数值校验，`service.py` 连接领域操作和材料存档，`storage.py` 负责内容寻址数据与历史记录，`server.py` 提供本地接口。`web/app.js` 使用接口构建交互页面，不自行推导独立口径。
